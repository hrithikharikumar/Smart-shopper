# 🛒 SmartShopper – Price Comparison Website

**SmartShopper** is a PHP-based web application that allows users to compare product prices across multiple e-commerce websites like **Amazon**, **Flipkart**, and **Snapdeal**.  
It features a modern, responsive interface built with **Material Design for Bootstrap (MDB Pro)** and custom **SCSS** styling, offering a smooth and intuitive shopping experience.

---

## 🚀 Features

- 🔍 **Compare Prices** – Quickly find the best deals from top online stores.  
- 🖼️ **Product Display** – Shows product image, title, and price details.  
- ⚡ **Responsive UI** – Works seamlessly across desktop, tablet, and mobile devices.  
- 💡 **PHP Backend** – Supports dynamic content and can be extended with real-time APIs.  
- 🎨 **Custom Styles** – Enhanced look using SCSS and MDB Pro design components.
